# Calculator-CSharp
# Hesap Makinesi

C# ve .NET Windows Forms kullanılarak geliştirilmiş, grafik arayüzlü (GUI) temel bir hesap makinesi uygulamasıdır.

## Özellikler
* Temel aritmetik işlemler (Toplama, Çıkarma, Çarpma, Bölme)
* Kullanıcı dostu, sade grafik arayüz
* Hatalı girişler ve sıfıra bölünme durumları için hata kontrolü

## Kurulum Talimatları
Uygulamayı kurmak için projeye dahil edilen `setup.exe` dosyasını kullanın.

1. `setup.exe` dosyasını çalıştırın.
2. **Son Kullanıcı Lisans Sözleşmesi (EULA):** Sözleşme ekranına geldiğinizde, metnin en altında rastgele oluşturulmuş **6 haneli bir doğrulama kodu** göreceksiniz.
3. **Doğrulama:** Kuruluma devam edebilmek ve "Kabul Ediyorum" butonunu aktifleştirmek için bu 6 haneli kodu sözleşmenin altındaki metin kutusuna eksiksiz girmeniz gerekmektedir.
4. Kodu girip onayladıktan sonra kuruluma devam edebilirsiniz. Uygulama varsayılan olarak `C:\Program Files (x86)\Calculator-CSharp` (veya belirlediğiniz isimdeki) dizine kurulacaktır.
5. İsteğe bağlı olarak masaüstü kısayolu oluşturma seçeneğini işaretleyin ve kurulumu tamamlayın.

## Kullanım
Kurulum tamamlandıktan sonra uygulamayı Başlat menüsünden veya masaüstü kısayolundan başlatabilirsiniz. Hesaplamalarınızı farenizle ekrandaki tuşlara tıklayarak veya klavyenizin numpad (sayısal tuş takımı) bölümünü kullanarak yapabilirsiniz.
